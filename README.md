# SUERF Policy Brief No. 1406 – Additional Materials

This repository contains the supplementary material for **SUERF Policy Brief No. 1406 (Banking on Decarbonization)**.

It hosts:

- `Toy Model - Climate Finance Risk Return Framework.xlsx` — spreadsheet with the toy model referenced in the brief.  
- `methodological_note.pdf` — methodological documentation linked in the brief.

These files provide the technical and analytical content supporting the SUERF policy note.

The original policy brief is published by **SUERF – The European Money and Finance Forum**:  
https://www.suerf.org/policynotes (or search for Policy Brief No. 1406 on SUERF.org)  [oai_citation:0‡GitHub](https://github.com/lmillischer/bankingondecarbonization)

No installation or special setup is required.
